## Course Format

This course is **fully remote and asynchronous**. Students are not required to attend scheduled class meetings or synchronous video sessions.

Each weekly module provides the materials needed to progress through the course, including recorded lectures, tutorials, readings, exercises, and project instructions. Students may work through course materials on their own schedules within the structure of the semester, but should keep pace with the weekly modules because later projects build on skills developed earlier in the course.

Questions, project discussions, and technical problems may be handled through the course communication channels and GitHub as directed by the instructor.

## Course Goals

This course trains students to build semantically interoperable systems using the full Semantic Web stack, automated reasoning, ontology validation, and ontology-based machine-learning and AI workflows.

The course progresses from development-environment setup and ontology-engineering methodology through RDF, RDFS, OWL, SPARQL, automated reasoning, SHACL, semantic pipelines, machine learning, embeddings, and LLM-supported ontology engineering.

Because the course is asynchronous, hands-on projects provide the primary structure for applying the material. The final cradle-to-grave project and recorded presentation require students to demonstrate their ability to model, query, reason over, validate, integrate, and augment knowledge using formal ontologies and contemporary AI tooling.
